# Mobile Design System

Created a seller-only mobile design guide from the supplied Agrivive design draft. The guide defines a single canonical palette, type and spacing rules, reusable components, seller navigation, key mobile screens, and accessibility checks.

**Why:** The supplied draft mixed two color palettes and included a buyer cart navigation pattern. The revised guide gives the React Native seller app one consistent visual source of truth and connects the guidance to listing, reservation, QR pickup, and insight flows.

**Affected file:** `mobile/DESIGN.md`.

**Verification:** Read the final guide for scope, checked that it contains seller mobile flows and no web implementation instructions, and compared the chosen tokens with the supplied draft. This is documentation; no runtime test applies.
