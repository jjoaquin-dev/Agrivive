# Seller Onboarding Concept

Created a first-screen mobile onboarding mockup for Agrivive's seller app. It introduces the core value: listing marketable surplus vegetables, reaching nearby buyers, and arranging self-pickup. The illustration depicts a Davao vegetable-market seller; the interface uses green, ivory, and warm amber.

**Why:** Give the mobile team a concrete visual direction and a reference for recreating the screen in Stitch or React Native.

The user supplied the official full logo and icon-only logo. Saved both original assets and created a revised mockup using that branding in the header. The original concept remains available for comparison. For implementation, use the original logo assets rather than extracting the logo from the generated mockup.

**Affected files:** `mobile/seller-onboarding-concept.png`, `mobile/seller-onboarding-concept-v2.png`, `mobile/agrivive-logo-full.png`, and `mobile/agrivive-logo-icon.png`.

**Verification:** Visually inspected both mockups for readable copy, clear primary action, and absence of extra illustration text. Checked that the supplied logo files and revised mockup were saved in `mobile/`. These are design assets; no runtime test applies.
