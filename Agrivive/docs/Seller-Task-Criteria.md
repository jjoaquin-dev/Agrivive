# Seller Task Criteria

Parent: [[Docs Index]]

**Project/System:** Agrivive (seller mobile app)
**Respondent:** ____________________
**Date:** ____________________
**Device:** ____________________

**Instruction:** Do each task. Mark Pass if you finished it alone, Fail if you could not. Then rate how easy it was.

**Ease scale:** 5 = Very easy · 4 = Easy · 3 = Okay · 2 = Hard · 1 = Very hard

| No. | Task Criterion | Steps to try | Expected result | Pass / Fail | Ease (1-5) | Remarks |
| --- | -------------- | ------------ | --------------- | ----------- | ---------- | ------- |
| S1 | **Can create an account** | Register and enter the code sent to your email. | Account is made and verified. | | | |
| S2 | **Can log in** | Sign in with email code or password, log out, sign in again. | You reach Home. Wrong details show a clear message. | | | |
| S3 | **Can finish profile setup** | Fill in the stall and profile details. | Setup checklist is complete and the stall shows. | | | |
| S4 | **Can post a listing** | Add a product with name, price, amount and photo, then save. | The listing shows in your list and in the marketplace. | | | |
| S5 | **Can edit a listing** | Change the price or details of a listing. | New details show right away. | | | |
| S6 | **Can change stock** | Use Add More, Take Away or Change Amount. | New amount shows and Change History records it. | | | |
| S7 | **Can promote (Boost)** | Open Boost, pick a listing, preview and start it. | Boost starts, or a plain reason shows why it cannot. | | | |
| S8 | **Can set an auto price drop** | Open Auto Price Drop and set it for a listing. | The rule is saved and shown on the listing. | | | |
| S9 | **Can handle a reservation** | Open a new reservation and confirm or cancel it with a reason. | Status changes and the buyer is told. | | | |
| S10 | **Can finish a pickup** | Scan the buyer's pickup pass and hand over. | Order becomes completed. | | | |
| S11 | **Can message a buyer** | Open Messages and reply to a buyer. | Reply is sent and shows in the chat. | | | |
| S12 | **Can read notices** | Open Notifications and the Home activity. | Latest updates show with correct status. | | | |
| S13 | **Can see advisories** | Open Advisories (weather, holidays, reminders). | Advice shows and is easy to read. | | | |
| S14 | **Can turn on extra sign-in safety** | Open Profile, Security and set up the two-step code. | Two-step code is on and works at next sign-in. | | | |
| S15 | **Can see standing and dispute a mark** | Open Trust standing and dispute a mark. | Score, reason and how to dispute show; dispute is sent. | | | |
