## Notes

1. AHP–TOPSIS is the default ranking, and the live site uses it.
2. The old formula is used only when `VISIBILITY_POLICY=visibility-v4`.
3. The first post is a normal post for any listing. Priority Boost (score 0.60 or higher) decides only whether the 6-hour price drops are offered. The score is checked once, at the first post.
4. Listings below Priority Boost keep the normal post and are told why price drops are off.
