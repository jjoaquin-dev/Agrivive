## Defects found

1. **WSV-008 (High), old baseline setting.** Paging repeats listings when scores tie. Likely fix: keep the score at full precision in the page marker, or round it the same way in the database comparison.
2. **Old baseline ranks old listings above fresh ones.** A 3-minute-old, full-stock listing scores 0.40, while a 13-hour-old, 5%-stock listing scores 0.42. This is how the old formula is built, but it contradicts WSV-001 and WSV-003.
3. **A missing VISIBILITY_POLICY means the old baseline.** AHP–TOPSIS is not live on your server until the value is exactly visibility-ahptopsis-v1.
