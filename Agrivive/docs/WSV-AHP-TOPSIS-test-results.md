## Defects found

1. **WSV-008 (High), old baseline setting. Fixed 2026-11-01.** Paging repeated listings when scores tied. The score is now rounded to 9 decimals in the database query. Confirmed on the live feed (48 listings, 38 tied scores) at five page sizes.
2. **Old baseline ranks old listings above fresh ones. Resolved by making AHP–TOPSIS the default.** The baseline formula is unchanged, because it is the rollback and rewards waiting by design. Fresh listings now rank first by default.
3. **A missing VISIBILITY_POLICY meant the old baseline. Fixed 2026-11-01.** AHP–TOPSIS is now the default, and only the exact value `visibility-v4` rolls back. The example env files were updated. **The VPS `.env` must be updated and the API container recreated** if it sets `VISIBILITY_POLICY=visibility-v4`.
